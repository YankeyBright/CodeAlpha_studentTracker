# Student Grade Tracker

> **CodeAlpha Java Programming Internship — Task 1**

A console-based Java program to input and manage student grades. It calculates average, highest, and lowest scores, and displays a summary report of all students.

## Features

- **Add Student** — Enter a student name and their grades (scores from 0 to 100)
- **View All Students** — See all students in a formatted table with their grades and averages
- **Edit Student** — Update a student's name or re-enter their grades
- **Delete Student** — Remove a student from the list (with confirmation)
- **Summary Report** — View class average, highest score, lowest score, and individual breakdown

## Technologies Used

- Java (JDK 21)
- ArrayList for data storage
- Scanner for console input

## How to Run

```bash
javac Student.java StudentGradeTracker.java
java StudentGradeTracker
```
